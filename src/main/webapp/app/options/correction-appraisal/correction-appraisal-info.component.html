Correction Appraisal Data

  1. Halaman ini adalah untuk memperbaiki data appraisal dengan status aktif(bukan complete / cancel / reject) yang tidak memiliki person in charge
  2. Pada filter section terdapat filter:
    • Ignore Active Position Type, filter ini berfungsi untuk mengabaikan aktif person in charge dengan position type yang dipilih.
  3. Klik pada data kolom appraisal number, cif, customer name untuk copy ke clipboard
